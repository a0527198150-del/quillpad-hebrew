# Quillpad בעברית — Release

גרסה עברית לא רשמית של Quillpad 1.5.15.

## פקודת בנייה ב-Windows

במאגר מקומי שכבר שוכפל, פתח CMD והרץ:

```bat
git pull && BUILD.cmd
```

בפעם הראשונה בלבד יש לשכפל את המאגר:

```bat
git clone https://github.com/a0527198150-del/quillpad-hebrew.git && cd quillpad-hebrew && BUILD.cmd
```

סקריפט הבנייה מייצר APK מסוג **Release**, חתום בחתימה עצמאית. הוא מעתיק את התוצאה אל תיקיית **Downloads** המוגדרת בחשבון Windows, בשם `Quillpad-Hebrew-release.apk`.

## מפתח החתימה — חשוב מאוד

בבנייה הראשונה נוצר מפתח חתימה פרטי, מחוץ לתיקיית Git, בנתיב:

`%LOCALAPPDATA%\Quillpad-Hebrew\signing\quillpad-hebrew-release.p12`

הסיסמה נשמרת בקובץ `password.dpapi` באותה תיקייה, מוצפנת עבור חשבון Windows הנוכחי. הקבצים אינם מועלים ל-GitHub.

**יש לגבות את שני הקבצים במקום בטוח.** סיסמת DPAPI לא ניתנת לפענוח בחשבון Windows אחר ללא אמצעי שחזור מתאימים; לכן, לפני פרמוט או מעבר מחשב, יש לתכנן גיבוי ושחזור של מפתח החתימה. אובדן המפתח ימנע התקנת עדכונים על אותה התקנה ללא הסרה.

זו אינה החתימה הרשמית של Quillpad. אם מותקנת האפליקציה הרשמית או גרסת Debug, ייתכן שיהיה צורך לגבות את הפתקים ולהסיר את הגרסה הקודמת לפני ההתקנה.

Gradle רשאי להוריד תלויות חסרות. תעודת NetFree מיובאת למאגר תעודות מקומי בלבד לצורך הבנייה, בלי לבטל אימות TLS.

קוד המקור הרשמי: https://github.com/quillpad/quillpad — רישיון GPL-3.0. אין הבטחה שהתרגום נבדק במכשיר או שתוצאת Release נבנתה בהצלחה עד שיתקבל `BUILD SUCCESSFUL`.
